⚠️ Важная информация

📷 Требуется веб-камера

Для работы AI ПОИСК необходима работающая камера. Можно использовать как встроенную камеру ноутбука, так и отдельную USB-веб-камеру. Если камера занята другой программой или Windows не предоставляет к ней доступ, распознавание работать не будет.

⏳ Программа может запускаться до 1 минуты 30 секунд

Внимание! AI ПОИСК может запускаться до 1 минуты 30 секунд, особенно при первом запуске. Если после запуска AI_POISK.exe окно не появилось сразу, не закрывайте программу — просто подождите. Не запускайте программу несколько раз подряд, пока предыдущий запуск ещё не завершился.

📷 Камера может запускаться до 1 минуты

После открытия программы подключение камеры также может занимать до 1 минуты. Это нормально. Подождите завершения запуска камеры перед использованием программы.

💾 Требуется свободное место

AI ПОИСК содержит необходимые компоненты искусственного интеллекта и поэтому занимает значительное количество места на диске. Также сохранённые фотографии занимают дополнительное место, если функция сохранения включена.

🛡️ Предупреждение Windows SmartScreen

При первом запуске Windows Defender SmartScreen может показать предупреждение о неизвестном или непроверенном приложении. Само появление такого предупреждения не означает автоматически, что программа является вредоносной. Самостоятельно собранные и малоизвестные программы могут получать такое предупреждение, особенно если они не имеют коммерческой цифровой подписи. Рекомендуется скачивать AI ПОИСК только с официальной страницы проекта и при желании дополнительно проверить файл антивирусом. Не отключайте защиту Windows целиком только ради запуска программы.

🐍 Python устанавливать не нужно

Для готового AI_POISK.exe пользователю не требуется отдельно устанавливать Python или библиотеки программы. Необходимые компоненты уже находятся внутри собранного приложения.

🔐 Конфиденциальность

AI ПОИСК использует изображение с камеры для выполнения функции распознавания объектов. Если включено сохранение фотографий, изображения сохраняются на компьютере пользователя. Не направляйте камеру на людей или территории, где съёмка запрещена или может нарушать права других людей.


Важно: результат работы искусственного интеллекта не всегда может быть абсолютно точным. Освещение, расстояние, угол обзора, качество камеры и другие условия могут влиять на распознавание.
